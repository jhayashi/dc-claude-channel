Per-Agent Tool Restrictions — UI Approaches

How should the tool picker appear in the agent-setup card?

A

Collapsible Sections (Recommended)

Each tool source is a collapsible group header. Tap to expand and see individual tools with checkboxes. A "select all / deselect all" toggle per group. Compact when collapsed — just shows "Built-in Tools (7/10)" and "DC Tools (5/5)".

Pros

  • Compact — groups stay collapsed until needed
  • Natural grouping by source
  • Quick scan: "7/10" tells you at a glance

Cons

  • More implementation work (collapsible sections)
  • Nested UI in an already-nested WebXDC card
B

Flat Checkbox List with Group Headers

All tools visible at once, organized under simple text headers. No expand/collapse — just scroll. Simpler to build, but longer on mobile.

Pros

  • Simplest to build
  • Everything visible — no hidden state

Cons

  • Long scroll on mobile with 15+ tools
  • No quick "all on/all off" per group
  • Pushes the Create/Save button way down
C

Separate Tools Tab/Screen

Keep the current create/edit form clean. Add a "Configure Tools" button that opens a dedicated screen for tool selection. Keeps the main form uncluttered.

Pros

  • Main form stays simple
  • Tool picker gets full screen real estate

Cons

  • Extra navigation step
  • Users might miss it entirely
  • More complex state management
